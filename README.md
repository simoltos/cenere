# Cenere

Cenere is an offline install wizard for Arch and Arch based distros.

System and home use the same Btrfs filesystem, with separate subvolumes
sharing the available space. Cenere can preserve an existing home on a
compatible Btrfs layout, including one created by another distro.

It also offers the user the choice to encrypt the disk and to unlocking an
alredy protected one in order to eventually preserve an home within.

It can install alongside an existing system, using free space or shrinking
a supported filesystem. The disk layout is shown before installation.
