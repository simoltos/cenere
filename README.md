# Cenere

Cenere is an offline install wizard for Arch and Arch based distros.

It's able to encrypt the system and preserving the home partition of
an alredy preent btrfs formatted disk with a compatible mountpoint,
so the system can be installed without wiping user's data.

It also offers the user the choice to encrypt the disk and to unlocking an
alredy protected one in order to eventually preserve an home within.

## Use

To use `cenere` there is an [INTEGRATION](INTEGRATION.md) guide.

Otherwise an arch based distro alredy featuring it will be ready ASAP.
